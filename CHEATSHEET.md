# cmdit — Shortcut Cheatsheet

## File

| Shortcut | Action |
|---------|--------|
| `Ctrl+S` | Save |
| `Ctrl+O` | Open file |
| `F3` | Save as |
| `F2` | Rename file |
| `F9` | Toggle auto-save |
| `Ctrl+Q` | Quit |

## Tabs & Splits

| Shortcut | Action |
|---------|--------|
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close tab |
| `F8` | Next tab |
| `F7` | Previous tab |
| `Ctrl+1` to `9` | Jump to tab N |
| `Ctrl+\` | Split / toggle pane |

## Editing

| Shortcut | Action |
|---------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+C` | Copy selection (or line) |
| `Ctrl+X` | Cut selection (or line) |
| `Ctrl+V` | Paste |
| `Ctrl+A` | Select all |
| `Backspace` | Delete char left |
| `Delete` | Delete char right |
| `Tab` | Insert 4 spaces |
| `Ctrl+D` | Add cursor (next occurrence) |
| `Esc` | Clear extra cursors |

## Navigation

| Shortcut | Action |
|---------|--------|
| `↑↓←→` | Move cursor |
| `Ctrl+←/→` | Jump word |
| `Home/End` | Line start/end |
| `Ctrl+Home/End` | File start/end |
| `PageUp/Down` | Scroll page |
| Mouse click | Position cursor |
| Mouse scroll | Scroll |

## Search

| Shortcut | Action |
|---------|--------|
| `Ctrl+F` | Find |
| `Ctrl+H` | Find & replace |

## Tools

| Shortcut | Action |
|---------|--------|
| `Ctrl+P` | Command palette |
| `F4` | Toggle auto-close brackets |
| `F5` | Toggle Vim mode |
| `F6` | Next theme |
| `Alt+Z` | Toggle word wrap |
| `Esc` | Close palette / cancel |

## Vim Mode (toggle with `F5`)

| Key | Action (Normal mode) |
|-----|----------------------|
| `h j k l` | Move cursor |
| `w b` | Next/prev word |
| `0 $` | Line start/end |
| `i I a A o O` | Enter insert mode |
| `x` | Delete char |
| `dd` | Delete line |
| `yy` | Copy line |
| `p P` | Paste after/before |
| `u Ctrl+R` | Undo/redo |
| `:w :q :wq` | Save/quit/save+quit |
| `Esc` | Normal mode |
