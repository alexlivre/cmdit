# cmdit Quickstart — 5 minutes to master

## Install

**Windows (PowerShell):**
```
irm https://raw.githubusercontent.com/alexlivre/cmdit/main/install.ps1 | iex
```

**Linux / macOS:**
```bash
curl -sSL https://raw.githubusercontent.com/alexlivre/cmdit/main/install.sh | bash
```

## Open a file

```bash
cmdit myfile.txt       # Opens existing or creates new
cmdit                  # Welcome screen with recent files
```

## Start typing

No modes. No `:wq`. No `hjkl`. Just type like Notepad.

| Action | Shortcut |
|--------|----------|
| Save | `Ctrl+S` |
| Quit | `Ctrl+Q` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` |
| Copy | `Ctrl+C` |
| Cut | `Ctrl+X` |
| Paste | `Ctrl+V` |

## What you need for the first 5 minutes

1. **Open** a file: `cmdit hello.txt`
2. **Type** something
3. **Save**: `Ctrl+S`
4. **Quit**: `Ctrl+Q`

That's it. You're done.
